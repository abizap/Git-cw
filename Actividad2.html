Código

    #include <stdio.h>
    int main() 
    {
        int edad;
        printf("¿Cuántos años tienes? ");
        scanf("%d", &edad);
        if (edad >= 18)     
        {
            printf("Eres mayor de edad.\n");
        }
        else 
        {
            printf("Eres menor de edad.\n");
        }
    return 0;
    }

Explicación:

Inclusión de librería

#include <stdio.h>

Incluye la librería estándar de entrada/salida, necesaria para usar printf y scanf.

Función principal

int main()

Todo programa en C comienza ejecutándose desde esta función.

Declaración de variable

int edad;

Declara una variable de tipo entero llamada edad para almacenar el número que ingrese el usuario.

Solicitar datos al usuario

printf("¿Cuántos años tienes? ");

Muestra el mensaje en pantalla.

scanf("%d", &edad);

Lee un número entero desde el teclado y lo guarda en la variable edad. El & indica la dirección de memoria donde se guarda.

Condicional if

if (edad >= 18)

Evalúa si la edad es mayor o igual a 18.

  • Si es verdadero ejecuta printf("Eres mayor de edad.\n");
  • Si es falso ejecuta printf("Eres menor de edad.\n");

Fin del programa

return 0;

Indica que el programa terminó correctamente.
