Etiquetas HTML - mi referencia

Etiqueta Para que sirve Ejemplo
ol Para realizar una lista de forma ordenada 

<ol>
    <li>Elemento 1</li>
    <li>Elemento 2</li>
</ol>
ul Para realizar una lista de forma desordenada 

<ul>
    <li>Elemento 1</li>
    <li>Elemento 2</li>
</ul>
th Para definir el encabezado de la columna 

<thead>
    <th>Etiqueta</th>
    <th>Para que sirve</th>
    <th>Ejemplo</th>
</thead>
td Para definir lo que hay en cada celda 

<tr>
    <td>etiqueta 1</td>
    <td>Para que sirve la etiqueta</td>
    <td>Ejemplo</td>
</tr>
thead Para introducir un encabezado en la tabla 

<thead>
    <th>Etiqueta</th>
    <th>Para que sirve</th>
    <th>Ejemplo</th>
</thead>
tbody Indica el cuerpo de la tabla 

<tbody>
    <tr>
        <td>Para que sirve</td>
    </tr>
</tbody>
table Para hacer una tabla 

<table>
    <tbody>
        <tr>
        <td>Para que sirve</td>
        </tr>
    </tbody>
</table>
